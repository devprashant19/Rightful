# Rightful: Agent Guidelines & Engineering Principles

> Derived from Andrej Karpathy coding principles and the Rightful Hackathon Master Plan.

## 1. Core Engineering Principles
1. **Simplicity Over Abstraction:** Write the simplest, cleanest TypeScript that works. Do not introduce speculative helper libraries, complex factory patterns, or unnecessary abstractions.
2. **Minimal, Surgical Diffs:** Touch only the files relevant to the active phase. Preserve working code, existing types, comments, and architecture.
3. **Verify Before Saying Done:** Never assert that a phase or task is complete. Prove it with real terminal output from `npm run build`, `npm run lint`, and test scripts.
4. **Deterministic Code Over AI Self-Claims:** In Rightful, the AI is a reasoning engine, not the final judge. The deterministic code verifier (`lib/verify.ts`) has final authority over policy quotes and date math.
